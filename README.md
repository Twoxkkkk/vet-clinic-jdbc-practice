# VetClinic

**Приложение для управления ветеринарной клиникой с ролевой моделью.**


## 🛠 Быстрый старт

Для использования приложения понадобиться **Docker** .

Перед началом по шаблону **postgre.env.example** создайте ***postgre.env*** и заполните значения для соотвествующих глобальных переменных.
```env
POSTGRES_USER=
POSTGRES_PASSWORD=
```

Далее запускаем скрипт запуска приложения:

``` bash
chmod +x run.sh
./run.sh
```
